## 3. Breaking changes to handle in this repo

Extracted from the official 13.x upgrade guide, ranked by relevance to the current codebase.

### High impact
- **CSRF middleware renamed** `VerifyCsrfToken` → `PreventRequestForgery`; now verifies
  `Sec-Fetch-Site` request origin. Update any `withoutMiddleware([...])` in tests and
  direct middleware references. Relevant to T1.2 auth replacement and T1.5 tenant routes.
- **Dependency bumps**: `laravel/framework ^13.0`, `laravel/tinker ^3.0`,
  `phpunit/phpunit ^12.0`, `laravel/boost ^2.0` (optional but supported), `pestphp/pest ^4.0`
  (not installed here). `spatie/laravel-permission` must move to a Laravel-13-compatible
  major alongside T1.3 — check its published constraint during `composer update`.

### Medium impact
- **Cache `serializable_classes`** defaults to `false`; applications caching PHP objects
  must allow-list them explicitly. No custom object caching found in the current repo, but
  T1.8 queue/cache work must respect this.
- **Database `upsert`** now throws `InvalidArgumentException` on empty `uniqueBy`. Audit
  any upsert calls added in later phases (tenant settings, plan seeding).
- **MySQL `DELETE … JOIN` with `ORDER BY`/`LIMIT`** now emits full syntax; MariaDB < 11.8.1
  may reject it. WAMP MySQL version must be recorded at test time.
- **Domain route registration precedence** — explicit-domain routes now match before
  non-domain routes regardless of registration order. This is directly relevant to the
  ratified OQ-022 tenant host resolution (T1.5): verify subdomain/custom-host routes behave
  as intended after the upgrade.

### Low / note
- Cache and Redis key prefixes change from `app_cache_` to `app-cache-` when relying on
  framework defaults. T1.8 will set explicit prefixes anyway; set them now to avoid surprise.
- Session `serialization` defaults to `json` in the 13.x skeleton — do not sync that config
  blindly or all active sessions will be invalidated. Keep `php` until a planned cutover.
- Queued notification missing-model behavior, `JobAttempted::$exception` replacing
  `$exceptionOccurred`, `QueueBusy::$connectionName`, `Container::call` nullable defaults,
  polymorphic pivot pluralisation, Str factories reset in tests, default password-reset
  subject "Reset your password" — scan tests/assertions when they are added.
- `symfony/polyfill-php85` defines `array_first()` / `array_last()` below PHP 8.5; prefer
  `Illuminate\Support\Arr` helpers in new code.
